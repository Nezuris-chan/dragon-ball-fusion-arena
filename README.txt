DRAGON BALL FUSION ARENA — VERSION BASEE SUR TON ANCIEN SCRIPT

Fichiers :
- index.html : ton jeu modifié, avec les dessins Canvas, animations, attaques, transformations et bonus conservés.
- guide.html : commandes, mécaniques, transformations et attaques par personnage.

Installation GitHub Pages :
1. Télécharge et extrais le ZIP.
2. Dans ton dépôt GitHub, remplace index.html par celui de cette version.
3. Ajoute guide.html à la racine du dépôt.
4. Valide (Commit changes), puis recharge le site avec Ctrl + F5.

Aucun dossier n'est nécessaire : les deux fichiers sont à la racine.

Notes :
- L'interface, les couleurs et les dessins d'origine du fichier fourni ont été conservés.
- Les campagnes ajoutées utilisent des dialogues originaux. AF et Kakumei sont identifiées comme fan-made.
- Le script a été vérifié pour sa syntaxe et lancé dans Chromium pour vérifier le menu, les campagnes et le démarrage d'un combat.
