DRAGON BALL FUSION ARENA — VERSION ORGANISÉE

Contenu :
- index.html : page de démarrage
- css/style.css : styles
- js/game.js : logique du jeu (gardée dans un seul fichier pour préserver les variables partagées)

Pour publier : envoyer les 3 éléments (index.html, css/, js/) à la racine du dépôt GitHub Pages, en conservant les dossiers.
Ne téléversez pas seulement index.html : les deux dossiers sont nécessaires.

Optimisation : rendu plafonné à environ 30 images/s, simulation de combat conservée à son rythme d’origine. Les erreurs JavaScript sont affichées dans un panneau rouge en bas de page.
