# Dragon Ball Fusion Arena — Prototype 0.1

Prototype de fan-game 2D jouable dans un navigateur, prévu pour être publié sur GitHub Pages.

## Lancer le jeu
- Ouvrir `index.html` dans un navigateur moderne, ou publier le dossier sur GitHub Pages.
- Aucun Node.js ni compilation n'est nécessaire.

## Commandes
- Joueur 1 : A/D pour bouger, W pour sauter, F pour frapper, G pour une attaque d'énergie, H pour une technique spéciale.
- Joueur 2 : flèches gauche/droite/haut, J pour frapper, K pour une attaque d'énergie, L pour une technique spéciale.
- Le guide détaillé se trouve dans `guide/personnages/index.html`.

## Contenu actuel
- Menu principal : Mode Histoire, Versus local, Entraînement, Guide des commandes.
- Campagnes séparées : GT, AF, Kakumei et histoires personnalisées (continuités de fan, non officielles).
- Inventaire et collection accessibles uniquement depuis le Mode Histoire.
- Prototype de combat 2D, progression sauvegardée dans le navigateur.

## À savoir
Cette version est une base jouable de développement, pas encore un jeu complet au niveau de finition de Dragon Ball FighterZ. Les personnages sont représentés par des sprites vectoriels provisoires dessinés en code ; les sprites animés détaillés, les coups propres à chaque personnage, les cinématiques et les musiques seront ajoutés dans les prochaines étapes. Aucun élément graphique officiel de FighterZ n'est repris.
